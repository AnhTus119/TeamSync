# M06 — Quản lý khoa học (quản lý dự án)

Chủ sở hữu: Thành viên 2. Ghi nhận **quá trình làm việc**: dự án, cột mốc, nhiệm vụ, phụ thuộc, minh chứng, duyệt, nghiệm thu.

## Luồng

```
Việc:     todo ──► in_progress ──► review ──(quản lý duyệt)──► done
            ▲          │  ▲           │
            └──────────┘  └─(trả lại, bắt buộc lý do)
Cột mốc:  open ──(quản lý gửi)──► pending_review ──(giám sát)──► accepted
                                        └──► changes_requested ──(gửi lại)──► pending_review
```

## Quy tắc nghiệp vụ

- Thành viên workspace tạo được dự án; người tạo thành quản lý. Có thể tạo từ **mẫu** (tạo sẵn cột mốc và việc, hạn tính theo ngày bắt đầu).
- Chỉ quản lý tạo/sửa/xóa việc, cột mốc, phụ thuộc. Người được giao phải là quản lý hoặc thành viên (không phải giám sát).
- Mỗi việc có **điểm khối lượng** 1/2/3/5. Đổi điểm, hạn, người làm đều ghi lịch sử (minh bạch cho sổ đóng góp).
- Chỉ người được giao hoặc quản lý đổi trạng thái. Không bắt đầu được khi còn **việc phụ thuộc** chưa xong (409 `BLOCKED_BY_DEPENDENCY`).
- Sang `review` phải có ít nhất một **minh chứng** (409 `EVIDENCE_REQUIRED`). `done` chỉ qua duyệt của quản lý; trả lại bắt buộc lý do.
- Phụ thuộc phải cùng dự án, không tự phụ thuộc, không tạo vòng (409 `DEPENDENCY_CYCLE`).
- Cột mốc chỉ gửi nghiệm thu khi mọi việc của nó đã xong. Giám sát nghiệm thu; dự án chưa có giám sát thì quản lý tự nghiệm thu. Đã nghiệm thu thì không sửa.
- Minh chứng: file (pdf, png, jpg, docx, xlsx, pptx, zip, txt; ≤ 10 MB, lưu trong `instance/uploads/`) hoặc link http(s).
- Mọi thay đổi gọi `services.log_history(...)` — M17 dựng lại trạng thái theo thời gian từ bảng `TaskHistory`.

## Endpoint

| Method | Endpoint | Mô tả |
|---|---|---|
| GET | `/api/templates` | Mẫu dự án |
| GET | `/api/projects` | Dự án mình tham gia |
| GET / POST | `/api/workspaces/{id}/projects` | Dự án trong workspace / tạo dự án `{name, description?, start_date?, due_date?, template_id?}` |
| GET / PATCH / DELETE | `/api/projects/{id}` | Xem / sửa / xóa (quản lý) |
| GET / POST | `/api/projects/{id}/milestones` | Cột mốc (kèm `task_count`, `done_count`) / tạo |
| PATCH / DELETE | `/api/milestones/{id}` | Sửa / xóa |
| POST | `/api/milestones/{id}/submit` | Gửi nghiệm thu |
| POST | `/api/milestones/{id}/review` | `{action: accept \| request_changes, note}` |
| GET / POST | `/api/projects/{id}/tasks` | `?status=&assignee_id=&milestone_id=&due=overdue\|today\|week` / tạo việc |
| GET / PATCH / DELETE | `/api/tasks/{id}` | Chi tiết (kèm minh chứng, phụ thuộc, `blocked`) / sửa / xóa |
| PATCH | `/api/tasks/{id}/status` | `{status: todo \| in_progress \| review, note?}` |
| POST | `/api/tasks/{id}/review` | `{action: approve \| return, note}` |
| POST / DELETE | `/api/tasks/{id}/dependencies[/{depends_on_id}]` | Thêm / bỏ phụ thuộc |
| POST | `/api/tasks/{id}/attachments` | multipart `file` hoặc JSON `{url}` |
| GET | `/api/attachments/{id}/download` | Tải file minh chứng (kiểm tra quyền) |
| GET / POST | `/api/tasks/{id}/comments` | Bình luận |
| GET | `/api/tasks/{id}/history` | Lịch sử thay đổi |

## Trang

`/projects`, `/projects/{id}` (Kanban), `/projects/{id}/milestones`, `/tasks/{id}`.
