# M20 — Tài khoản, SSO và phân quyền

Chủ sở hữu: Đoàn Anh Tú. Xác định **ai được làm gì**: tài khoản, không gian làm việc, vai trò, lời mời, quản trị.

## Vai trò

| Cấp | Vai trò | Quyền chính |
|---|---|---|
| Hệ thống | `admin` | Mọi quyền; quản lý người dùng, dự án, mẫu dự án, ẩn bình luận |
| Hệ thống | `user` | Tạo workspace, tạo dự án, nhận lời mời |
| Workspace | `owner` | Sửa/xóa workspace, thêm/xóa thành viên, xem mọi dự án và tổng quan |
| Workspace | `member` | Tạo dự án trong workspace |
| Dự án | `manager` | Mời người, đổi vai trò, giao việc, duyệt/trả lại, gửi nghiệm thu cột mốc |
| Dự án | `member` | Làm việc được giao, nộp minh chứng, bình luận, đánh giá chéo |
| Dự án | `supervisor` | Xem toàn bộ, bình luận, nghiệm thu cột mốc; không sửa việc |

## Dùng hàm phân quyền (cho M06, M17)

```python
from ..m20_accounts.permissions import (MANAGER, WORKERS, SUPERVISORS, login_required, role_required,
                                        check_project_access, check_workspace_access, current_user, project_role)

check_project_access(pid)            # mọi người trong dự án + chủ workspace + admin (xem)
check_project_access(pid, MANAGER)   # chỉ quản lý (và admin)
check_project_access(pid, WORKERS)   # quản lý + thành viên, không gồm giám sát
check_workspace_access(wid)          # thành viên workspace + admin
check_workspace_access(wid, owner=True)
```
Sai quyền tự trả 403 `FORBIDDEN`, chưa đăng nhập 401 `UNAUTHORIZED`, không có đối tượng 404 `PROJECT_NOT_FOUND` / `WORKSPACE_NOT_FOUND`.

Hàm gọi chéo: `services.add_member(project_id, user_id, "manager")` (M06 gọi khi tạo dự án), `services.ensure_workspace_member(...)` (người nhận lời mời tự vào workspace).

## Quy tắc nghiệp vụ

- Tài khoản tự đăng ký luôn là `user`; email lưu chữ thường; mật khẩu ≥ 6 ký tự, băm bằng werkzeug.
- Tài khoản bị khóa không đăng nhập được và bị đăng xuất ở request kế tiếp. Admin không tự khóa / tự đổi vai trò.
- Mỗi dự án luôn có đúng 1 quản lý; muốn đổi thì chuyển quyền (`PATCH ... {"project_role": "manager"}`).
- Không xóa quản lý; không xóa hoặc chuyển sang giám sát người còn việc chưa xong.
- Lời mời dùng một lần, chỉ đúng email được mời mới nhận được; chỉ mời với vai trò `member` hoặc `supervisor`.
- Workspace chỉ xóa được khi không còn dự án; không xóa thành viên còn ở trong dự án của workspace.

## Endpoint

| Method | Endpoint | Mô tả |
|---|---|---|
| POST | `/api/auth/register` | `{email, password, full_name}` → 201 |
| POST | `/api/auth/login` | `{email, password}`; lưu Session |
| POST | `/api/auth/logout` | Đăng xuất |
| GET | `/api/auth/me` | Người đang đăng nhập |
| PATCH | `/api/auth/me/password` | `{old_password, new_password}` |
| GET | `/api/workspaces` | Workspace của mình, kèm `my_role`, `project_count` |
| POST | `/api/workspaces` | `{name, description?}`; người tạo là chủ |
| GET / PATCH / DELETE | `/api/workspaces/{id}` | Xem / sửa / xóa (chủ) |
| GET / POST | `/api/workspaces/{id}/members` | Danh sách / thêm theo email (chủ) |
| DELETE | `/api/workspaces/{id}/members/{user_id}` | Xóa thành viên (chủ) |
| GET | `/api/projects/{id}/members` | Thành viên dự án |
| PATCH / DELETE | `/api/projects/{id}/members/{user_id}` | Đổi vai trò / xóa (quản lý) |
| GET / POST | `/api/projects/{id}/invitations` | Lời mời đang chờ / tạo lời mời (quản lý) |
| DELETE | `/api/invitations/{id}` | Hủy lời mời |
| GET | `/api/invitations/{token}` | Thông tin lời mời |
| POST | `/api/invitations/{token}/accept` | Nhận lời mời |
| GET / PATCH | `/api/admin/users`, `/api/admin/users/{id}` | Lọc người dùng / đổi vai trò, khóa |
| GET | `/api/admin/projects` | Giám sát mọi dự án |
| PATCH | `/api/admin/comments/{id}` | `{is_hidden}` ẩn bình luận vi phạm |
| POST / PATCH / DELETE | `/api/admin/templates`, `/api/admin/templates/{id}` | Quản lý mẫu dự án |
